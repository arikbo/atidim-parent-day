התקנת מערכת תמונת תלמיד – ללא תשלום נוסף

המערכת משתמשת ב-GitHub Pages להצגת האתר וב-Firebase Spark להזדהות ואחסון. אין צורך במנוי AI. לפני העלאת נתוני תלמידים אמיתיים יש לבדוק פרטיות, הרשאות ותנאי השימוש המוסדיים.

א. Firebase – פעם אחת

  1. היכנס ל-Firebase Console ופתח פרויקט חדש בתוכנית Spark. אל תפעיל Billing/Blaze.
  2. בתפריט Authentication → Sign-in method הפעל Google.
  3. בתפריט Firestore Database צור מסד נתונים. בעת ההקמה בחר מצב נעול/Production, ולא Test Mode.
  4. בתפריט Firestore → Rules הדבק ופרסם את כל תוכן הקובץ firestore.rules.
  5. Project settings → Your apps → Web: צור Web App. העתק את ארבעת הפרטים לקובץ firebase-config.js.
  6. Authentication → Settings → Authorized domains: הוסף את הדומיין USERNAME.github.io של אתרך.

ב. GitHub

  1. צור מאגר ציבורי חדש (למשל atidim-parents). העלה את הקבצים שבתיקייה הזאת בלבד — בלי PDF, Excel או נתוני תלמידים.
  2. Settings → Pages → Deploy from a branch → main / root.
  3. פתח את הקישור שהתקבל ב-GitHub Pages.

ג. הפעלת מנהל המערכת בפעם הראשונה

  1. התחבר באתר עם חשבון Google שלך.
  2. בחר את שמך והגש בקשת הצטרפות. בשלב הראשון, אם אין שמות מורים במאגר, ניתן להקליד שם חופשי.
  3. פתח Firebase Console → Firestore → profiles → המסמך שמזההו ה-UID שלך.
  4. ערוך את המסמך והוסף/עדכן את השדות: status = approved, role = admin, teacherId = admin_initial, classes = [] (array), grades = [] (array). אין לאשר מנהל דרך משתמש רגיל.
  5. רענן את האתר. יופיע מסך ״ניהול וייבוא״. קרא את ההערה על איתור השיבוצים לפני העלאת PDF אמיתי.

ד. בדיקת הרשאות

  1. צור מורה בדוי ובקשת הצטרפות עם חשבון Google שני שבשליטתך או עמית מורשה.
  2. אשר את החשבון כמורה רגיל וודא שלא מוצגים תלמידים ללא שיבוץ.
  3. צור שיבוץ בדוי ובדוק שהמורה רואה אך ורק אותו.
  4. בדוק שאפשרויות מנהל/מחנך אינן מוצגות למורה רגיל ושניסיונות גישה ישירה ל-Firestore נבלמים על ידי הכללים.

ה. מגבלות חשובות של גרסה 1

זיהוי שיבוצי מורים מתוך PDF עברי אינו מדויק בכל פורמט; חייבים לבדוק את התצוגה לפני ייבוא ולתקן טעויות בשיבוצים דרך Firebase Console. בעת ייבוא מחדש, שיבוצים ישנים אינם נמחקים אוטומטית. ניתן להפיק PDF באמצעות ״הדפסה / שמירה כ-PDF״ בדפדפן; הדוחות לא נשמרים בענן. ההדפסה מוגבלת לעמוד לכל תלמיד, ואם יש יותר מדי תוכן היא עלולה להיחתך — חייבים לצפות בתצוגה המקדימה. אין לפרסם מידע טיפולי רגיש ללא בדיקה פרטנית ואישור מתאים.

בחשבון מורה נוסף לאותו אדם, מגישים בקשת הצטרפות נוספת ומאשרים אותה עם אותו teacherId. אין שיתוף סיסמאות.

פרויקט זה הוא גרסת פיילוט עובדת עם Firebase לאחר התקנה, ולא מערכת מאושרת אוטומטית לשימוש בנתוני תלמידים. יש לבדוק את ההרשאות במבחנים לפני מעבר לנתונים אמיתיים.
