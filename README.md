# תמונת תלמיד – עתידים (פיילוט חינמי)

ראו `README.html` להוראות התקנה בעברית.

* GitHub Pages: קוד ממשק בלבד. אין להעלות שום PDF/Excel/קובץ נתוני תלמידים למאגר הציבורי.
* Firebase Spark: Google Authentication + Cloud Firestore. **אין לשדרג ל-Blaze** אם נדרשת עלות אפס.
* `firestore.rules` חייב להיות מפורסם לפני שימוש. ברירת המחדל היא חסימת גישה לנתוני תלמידים עד אישור מנהל.
* אימות מתבצע מול Firebase Authentication, הרשאות נאכפות ב-Firestore Rules לפי UID, role ו-teacherId.
* ניתן לאשר שני חשבונות Google לאותו teacherId.
* מנהל ראשון מאושר ידנית ב-Firebase Console; אין הסלמת הרשאות דרך ממשק ההצטרפות.
* הייבוא מן הקבצים הוא גרסה ראשונית; יש לבדוק כל שיבוץ מול המסמך המקורי.
* הדפסה יוצרת דפי A4, ללא API/קרדיטים של AI.

## קיבולת חינמית (לפי Firebase, יש לבדוק מכסות בעת פריסה)
Cloud Firestore Spark: 50,000 קריאות ליום, 20,000 כתיבות ליום ו-1GiB אחסון בסיסי. חריגה מהמכסות תחסום פעולות ולא תחייב אוטומטית אם נשארים ב-Spark. עומסים, כללים ומגבלות אחרים עשויים להשפיע.

## בדיקות חיוניות לפני נתוני אמת
- בדיקות הרשאות יזומות לחשבונות שונים ובפרט ניסיון קריאת מידע שאינו שייך למורה.
- בדיקת שיוך כתובות Gmail ו-UID ובדיקה ידנית של מורים עם שם דומה.
- בדיקת נתוני PDF עבריים ומקרים של שמות כפולים; מומלץ לעבור בהמשך למזהה תלמיד רשמי במקום שם+כיתה.
- סגירת הרשאות עקב עזיבת מורה, גיבויים, מחיקה ושמירת מידע על פי הנחיות המוסד.
- בדיקת הדפסת דוחות מרובי מקצועות ללא חיתוך.
- אין לייבא או להציג אוטומטית נתונים רפואיים/טיפוליים או CBT.
